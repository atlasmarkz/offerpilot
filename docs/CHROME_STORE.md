# 发布到 Chrome 应用商店

扩展已经准备到“可以直接上传”的状态：权限收紧、zip 已打包、商店截图和宣传图已生成、文案已写好。**注册开发者账号、验证身份、支付 5 美元注册费、点击提交，必须由你本人完成**，下面是逐步清单。

## 0. 先确认两件事

1. **正式域名**：扩展只在你的网站上接收同步的画像，域名写死在构建里。当前使用 `https://offerpilot-rose.vercel.app`。如果以后换域名，要重新构建并发布新版本。
2. **隐私说明页能公开访问**：商店要求填隐私政策链接。把最新代码部署后，确认 `https://你的域名/privacy` 能打开，并且里面有“浏览器扩展”一节（已写好）。

## 1. 注册开发者账号（只有你能做）

1. 打开 <https://chrome.google.com/webstore/devconsole>，用一个 Google 账号登录（建议用专门的账号，比如你之前建的 OfferPilot 的 Gmail）。
2. 账号需要开启两步验证。
3. 一次性支付 **5 美元**注册费。
4. 在“账号”里填开发者名称，并验证**联系邮箱**。
5. 如果要提供付费功能，商店会要求你声明自己是不是“商家”，商家需要填联系地址。这个扩展本身免费，按实际情况选择即可。

## 2. 打包

```bash
cd apps/extension
WXT_WEB_ORIGIN=https://offerpilot-rose.vercel.app npx wxt zip
```

产物：`apps/extension/.output/offerpilot-extension-1.0.0-chrome.zip`（约 78 KB）。

包里的 manifest 只有三项权限：`storage`、`activeTab`、`scripting`，**没有任何网站的常驻访问权限**，同步脚本只匹配你的网站。

**每次更新要先把 `apps/extension/package.json` 的 `version` 加一，再重新打包上传。**

## 3. 上传并填写商店信息

在开发者后台点“新增商品”，上传 zip，然后按下面填写。

### 商品详情

| 项 | 填写 |
|---|---|
| 名称 | OfferPilot 校招填表助手 |
| 摘要（≤132 字符） | 在校招投递页一键填入你的基础信息（姓名、学校、专业、学历、毕业年份）。只填不提交，验证码由你自己完成。 |
| 类别 | 工作效率（Productivity） |
| 语言 | 中文（简体） |

**详细说明**（可直接粘贴）：

```
OfferPilot 校招填表助手，配合 OfferPilot 网站使用，帮你在各公司的校招投递页里，一键填入重复的基础信息。

【怎么用】
1. 在 OfferPilot 网站填写或导入你的求职画像，点“同步到浏览器扩展”。
2. 打开公司的投递页，点击浏览器工具栏里的扩展图标，再点“填写当前页面”。
3. 检查填好的内容，自己点击提交。

【它会做什么】
• 按表单的字段标签，识别并填入：姓名、毕业院校、专业、学历、毕业年份。
• 学历是下拉框时自动选择；自定义的下拉框、日期选择器会提示你手动选择。
• 页面上已经有内容的字段不会被覆盖。

【它不会做什么】
• 不会替你点击“提交”。
• 不会填写手机号、邮箱、证件号、密码，也不会上传文件。
• 遇到验证码、短信验证，会停下来交给你自己完成。
• 不会常驻读取任何网页：只在你点击扩展图标里的按钮时，对你当前这一个标签页运行一次。

【隐私】
你的画像只保存在你本机浏览器的扩展存储里，扩展自己不会向任何服务器发送数据。卸载扩展即清除。

需要配合 OfferPilot 网站的账号或本地版本使用。网站：https://offerpilot-rose.vercel.app
```

### 隐私规范标签页

**单一用途说明：**

```
在用户点击时，把用户同步到扩展里的求职基础信息（姓名、学校、专业、学历、毕业年份），填入当前投递页的对应表单字段。
```

**权限理由：**

| 权限 | 理由 |
|---|---|
| storage | 在用户本机保存从 OfferPilot 网站同步过来的求职画像，供填表使用。 |
| activeTab | 仅在用户点击扩展图标并按下“填写当前页面”时，临时访问当前这一个标签页，用来填写表单。 |
| scripting | 配合 activeTab，把填表脚本注入到用户当前点击的这一个标签页。没有任何常驻的网站访问权限。 |

**主机权限**：没有申请。扩展里有一个只匹配 OfferPilot 网站的内容脚本，用来接收网页同步过来的画像。

**是否使用远程代码**：否。所有代码都在扩展包里。

**数据使用披露**（勾选与说明）：
- 收集的数据类型：勾选“个人身份信息”（姓名、学校、专业等求职画像）。说明：只在用户本机的扩展存储里使用，不传输。
- 三项声明都勾选：不向第三方出售或转让用户数据（获批用途除外）；不为与扩展单一用途无关的目的使用或转让数据；不为判断信用或放贷目的使用数据。

**隐私政策链接**：`https://offerpilot-rose.vercel.app/privacy`

### 分发

- 可见性：建议**第一次先选“不公开”（Unlisted）**，拿到链接后自己装一遍确认无误，再改成公开。
- 地区：按需选择（中国大陆用户访问 Chrome 应用商店本身可能有限制，这不是扩展的问题）。

## 4. 提交与审核

点“提交审核”。首次审核通常需要几天，有时更久；如果被拒，邮件和后台会写明原因。常见拒绝原因以及这个扩展怎么避开的：

| 常见原因 | 本扩展 |
|---|---|
| 权限过大 / 申请了用不到的权限 | 只有 3 项，都在上面写明了理由；没有主机权限 |
| 隐私政策缺失或没覆盖扩展 | `/privacy` 里有“浏览器扩展”一节，并且是公开页面 |
| 描述含糊、截图误导 | 描述写明做什么、不做什么；截图是真实运行结果，并标注为演示表单 |
| 单一用途不清 | 只做一件事：把基础信息填进投递表单 |
| 使用远程代码 | 没有 |

## 5. 上架之后

- 商店链接生成后，告诉我，我把它加到网页端“同步到浏览器扩展”旁边，让用户一键安装。
- 之后每次改扩展：`package.json` 版本号 +1 → 重新 `wxt zip` → 在后台“程序包”里上传新版本。
- 如果换了网站域名：用新的 `WXT_WEB_ORIGIN` 构建新版本，并更新隐私政策链接和商店说明。

## 6. 自测清单（上传前）

1. `chrome://extensions` 开启开发者模式 → 解压 zip → “加载已解压的扩展程序”。
2. 打开 OfferPilot 网站 → 填画像 → “同步到浏览器扩展”，应显示“已同步”。
3. 打开任意招聘页的表单，点扩展图标 →“填写当前页面”，应填好姓名、学校、专业，学历下拉按页面情况选择或提示手动。
4. 确认：没有点击提交、没有动手机邮箱字段、页面已有内容没被覆盖。
5. 打开 `chrome://extensions` 里该扩展的“详情”，“网站访问权限”应只有你的网站，没有“所有网站”。
